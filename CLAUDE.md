# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`github.com/TechAlkurn/core` is a shared Go library (no `main` package) consumed by other services via `go get github.com/TechAlkurn/core`. Host apps are a Gin REST gateway in front of an internal gRPC server, and this module holds the shared pieces of both. Changes here affect every downstream app, so keep exported function signatures stable.

**Never import a host-app package** (e.g. its generated protos under `pkg/protos`). Host types come in through interfaces or generics instead: `action.ProtoResponse`, `register.RequestMessage`/`ResponseMessage`, `activerecord.Payload`, `activerecord.QueryReader`. `cons/` mirrors the host's `pkg/enum` values and error messages by hand, so keep the two in sync.

## Commands

```bash
go build ./...
go vet ./...
go test ./...                                   # tests in reqctx, register, config, db/hooks, db/activerecord
go test ./register -run TestName                # single test
go generate ./register/...                      # regenerate register/internal/testpb (needs protoc + protoc-gen-go/-go-grpc)
```

`register/internal/testpb` is a test-only copy of the host's Request/Response/CoreService protos, so `register` tests run without a host import. `docs/` is generated by swaggo/swag, so don't edit it by hand.

`make up m="commit message"` runs `git add . && git commit && git push origin main`, which pushes straight to the remote. Don't run it unless the user asks. After the push it runs `make publish`, which asks `proxy.golang.org` for the exact HEAD commit and prints `go get github.com/TechAlkurn/core@<hash> && go mod tidy` for the apps that use this module. Tell users to pin that hash, not `@latest`: the proxy caches `@latest`, so right after a push it can resolve an older commit and fail with "module ... found, but does not contain package ...". The other option is `go env -w GOPRIVATE=github.com/TechAlkurn/*`.

## Request identity (read before touching auth / logged-in user code)

`reqctx` carries the per-request identity (`Identity{UserID, Username, Email, Lang}`) and the current gRPC request. It replaces the old process-wide `lib.SetMuStorage`/`GetLoggedId`, where concurrent requests overwrote each other's user. Use `reqctx` in new code.

Flow across the REST → gRPC boundary:
1. `components/middleware/jwt.authenticate.go` verifies the token and puts the `Identity` into `c.Request.Context()` (`reqctx.With`).
2. The gRPC client interceptor `config.GrpcAuthClientUnary/Stream` sends the shared secret header `x-internal-auth` along with identity metadata. The token is `GRPC_AUTH_TOKEN`, or else an HMAC derived from `SECRET_KEY`, and it fails closed when neither is set.
3. `config.GrpcAuthServerUnary/Stream` rejects calls that lack the secret. The identity headers are trusted only because that check runs first.
4. `register`'s `RecoveryInterceptor`/`StreamContextInterceptor` call `reqctx.Bind(id, req)` for the duration of the RPC. That lets code with no `ctx` (forms, services, helpers) call `reqctx.UserID()`, `reqctx.Lang()`, `reqctx.IsOwner()` and `reqctx.Request()`.

The goroutine-bound store **does not cross `go func()`**, so use `reqctx.Go(fn)` for background work.

`lib/jwt.go` (golang-jwt v5, HS256) is the older path. `ValidateJWT`/`LoggedUser` still write the `id` claim into the global mutex map. `GenerateJWT` sets `exp` from `TOKEN_TTL` seconds (no expiry when that is unset or 0). `JwtGenerate` sets a 5-year `exp`. For old tokens the validator falls back to the legacy `logged_id` claim. `components/authorization` has a separate JWT and refresh-token implementation (`TOKEN_MAXAGE`) plus PASETO (`PASETO_KEY`).

## Architecture

- **`action/`**: Gin glue.
  - `request.go`: `Context` wraps a raw query string in an `*http.Request` (`Query`, `SetQueryParam`, `IgnoreNotification` → `is_ignore`). `RawQuery` is assigned verbatim on purpose, to keep the param order.
  - `response.go`: `Gin.Response(ProtoResponse)` builds the JSON envelope `{status, message, token, data}`. Proto `Data` is JSON bytes. Top-level `token`/`message` keys are removed from `data`, and they fill the envelope only when the proto's own fields are empty. Empty data becomes `[]`. `Abort`/`Failed` strip the gRPC `"desc = "` prefix. `SafeResponseMiddleware` guards against double writes.
- **`register/`**: the generic gRPC↔Gin bridge. `NewGrpcAction[Req, Res]()` is built from the host's generated message types; `HandleGrpc`/`GrpcHandle` wrap gRPC calls as Gin handlers and build the request from `gin.Context`. It also holds the gRPC recovery/identity interceptors and panic reporting to GitLab issues (`GITLAB_PROJECT_ID`).
- **`config/`**: host startup wiring, made of `Init*` functions (`InitEnv` loads `.env`, `.env.local` or `.env.staging`, and skips the panic when `ROOT` is already set, as in Docker), plus `InitDB`, `InitRedis`, `InitAws`, `InitLog`, `InitCmd` (cobra), `InitSwagger`, `InitGrpcClient`/load balancer, `RunServer`, rate limiting, pprof, DB dump/restore and gRPC auth.
- **`components/`**: reusable feature modules.
  - `middleware`: JWT auth, RBAC, recovery, timeout, Prometheus metrics.
  - `rbac`: a port of Yii2's `yii\rbac\DbManager` with the same table schema. Ops are dispatched by `?key=<op>`.
  - Others: `gateway` (Stripe, etc.), `mailers` (with `drivers/`, e.g. Mailjet), `fcm`, `sms`, `socket`, `agora`, `uploader`, `image`, `calendar`, `cache`, `mutex`, `attempt`, `githelper`, `console`.
- **`db/`**: the GORM data layer. Hosts must call `db.SetConnection(*gorm.DB)` and `db.SetLogger(Logger)` at startup, because `db.Connection()` panics otherwise.
  - `activerecord/`: generic `ActiveRecord[T]` (FindOne/FindAll/Count/SaveDB/DataQuery…), `Transaction`/`InTx`, `Exec`. Also the generic CRUD for gRPC services (formerly `components/base`): `Search`/`View`/`Del[T]` over a `Payload`, `BaseForm[T]` (body overrides query params), `SyncChildren`, and `Mapper` (`activerecord.ToMapped(in.Form).ToString("title")`) for panic-free reads of the decoded form.
  - `hooks/`: a registry of before/after save/update hooks for each model.
  - `drivers/`: the MySQL connection (`NewMysql` reads `DB_NAME`, `DB_URL`) and schema introspection.
  - `query/`: raw-SQL helpers such as `ResetTables`. It validates and backtick-quotes identifiers and pins a single connection so `FOREIGN_KEY_CHECKS` can't leak into other pooled sessions.
- **`components/cache/`** (and `components/mutex/`): in-memory `NewMutexCache`/`NewRWMutexCache`. The RW one adds `GetDefault`/`GetOrSet*`. The constructors return unexported types.
- **`cons/`**: constants, error messages and raw SQL strings, kept in sync with the host's `pkg/enum`.
- **`lib/`**: PHP-style helpers (`InArray`, `Explode`, `Strtotime`, `Empty`, `ToUint32`/`ToString` loose conversions, …).
  - `security.go`: bcrypt, plus `Encrypt`/`Decrypt` using AES-256-GCM (`nonce||ciphertext`) with a key derived from `ENCRYPTION_KEY`; `Encrypt` errors if that is unset. `Decrypt` falls back to the old AES-CFB format with the hard-coded `legacyEncryptionKey` so existing data still decrypts. **Never encrypt with the legacy key.** `SecurityEncrypt` produces `v1::<base64>`.
  - `datatype.go`: `BindJSON`/`ShouldBindJSON` expect a body wrapped as `{"form": {...}}` and return the inner object. `ShouldBindJSON` also rejects anything other than POST/PUT/PATCH.
  - `datetime.go`: `DateTime` with JSON and SQL support, layout `2006-01-02 15:04:05`.
  - `image.go`: local thumbnails only. The S3 resize/upload code is commented out.
  - `ics/`: `.ics` generation from text templates.

## Configuration

All config comes from env vars, read at call time. Main ones: `SECRET_KEY`, `TOKEN_TTL`, `TOKEN_MAXAGE`, `ENCRYPTION_KEY`, `PASETO_KEY`, `SITE_NAME`, `SITE_MODE`, `API_ENDPOINT`, `ROOT`, `DB_NAME`, `DB_URL`, `REDIS_ADDR`, `GRPC_HOST`, `GRPC_PORT`, `GRPC_TARGETS`, `GRPC_AUTH_TOKEN`, `GRPC_INTERNAL_KEY`, `GRPC_REFLECTION`, plus S3, Stripe, Mailjet and image-path vars in their own packages.

## Logging

More than one logger is in use: `action` uses a logrus `Log` but passes zap fields to it, and `lib/errors.go` uses the grpc-filetransfer logger. Match whatever the file you're editing already uses.
